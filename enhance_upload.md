│ Plan to implement                                                                                                                                                                                        │
│                                                                                                                                                                                                          │
│ Fix Upload Reliability for Large Files on Mobile                                                                                                                                                         │
│                                                                                                                                                                                                          │
│ Context                                                                                                                                                                                                  │
│                                                                                                                                                                                                          │
│ When uploading large images or videos from a phone, the upload can silently stall or fail — the browser's fetch() hangs indefinitely, the phone may kill the background tab, or the network drops. The   │
│ UI stays stuck at "uploading 30%" forever because:                                                                                                                                                       │
│                                                                                                                                                                                                          │
│ 1. No upload timeout — fetch() to R2 has no timeout, so a stalled connection hangs forever                                                                                                               │
│ 2. No real progress tracking — progress jumps from 10% → 30% → 80% (fixed milestones), never showing actual bytes transferred. Users can't tell if the upload is still active or frozen                  │
│ 3. No elapsed time / speed indicator — no way to gauge if things are moving                                                                                                                              │
│ 4. Stale "uploading" status text — only shows "uploading" / "processing" with no visual distinction between active transfer and a stalled one                                                            │
│                                                                                                                                                                                                          │
│ Plan                                                                                                                                                                                                     │
│                                                                                                                                                                                                          │
│ Step 1: Real upload progress via XMLHttpRequest + timeouts (use-media-upload.ts)                                                                                                                         │
│                                                                                                                                                                                                          │
│ Replace the fetch() PUT to R2 with XMLHttpRequest which supports upload.onprogress events. This gives actual byte-level progress instead of fake milestones.                                             │
│                                                                                                                                                                                                          │
│ New helper xhrUpload(url, file, contentType, onProgress): Promise<void>:                                                                                                                                 │
│ - Uses XMLHttpRequest with upload.onprogress for real byte progress                                                                                                                                      │
│ - Calls onProgress(loaded, total) on each event                                                                                                                                                          │
│ - Stall timeout (30s with no progress event) — aborts XHR and throws so retry logic kicks in                                                                                                             │
│ - Overall timeout (10 minutes) — aborts on exceed                                                                                                                                                        │
│ - Returns a Promise that resolves/rejects based on XHR load/error/timeout events                                                                                                                         │
│                                                                                                                                                                                                          │
│ Updated progress mapping:                                                                                                                                                                                │
│ - 0-5%: presigning                                                                                                                                                                                       │
│ - 5-90%: actual R2 upload (mapped from XHR progress)                                                                                                                                                     │
│ - 90-95%: confirming                                                                                                                                                                                     │
│ - 95-100%: complete                                                                                                                                                                                      │
│                                                                                                                                                                                                          │
│ Add AbortController timeouts to presign and confirm fetch() calls (30s each) so they don't hang on flaky connections.                                                                                    │
│                                                                                                                                                                                                          │
│ Extend UploadProgress interface with new fields:                                                                                                                                                         │
│ - bytesLoaded?: number — bytes uploaded so far                                                                                                                                                           │
│ - bytesTotal?: number — total file size                                                                                                                                                                  │
│ - startedAt?: number — Date.now() when upload began                                                                                                                                                      │
│                                                                                                                                                                                                          │
│ Add retryUpload(fileId) method — allows manual retry of a failed upload from the UI.                                                                                                                     │
│                                                                                                                                                                                                          │
│ Step 2: Richer upload row UI (group page page.tsx)                                                                                                                                                       │
│                                                                                                                                                                                                          │
│ Replace the current minimal upload row with visual feedback users can understand at a glance:                                                                                                            │
│                                                                                                                                                                                                          │
│ - Progress bar — thin colored bar (blue active, green complete, red error, yellow retrying)                                                                                                              │
│ - Bytes transferred — "142 MB / 500 MB" using existing formatBytes() from src/lib/utils/index.ts                                                                                                         │
│ - Upload speed — "2.3 MB/s" computed from bytesLoaded and startedAt                                                                                                                                      │
│ - Status indicators — spinner for active, checkmark for complete, warning icon for error, retry icon for retrying                                                                                        │
│ - Retry button on error rows — calls retryUpload(fileId) for manual retry                                                                                                                                │
│ - Stall hint — if status is "uploading" but progress hasn't changed for 10+ seconds, show "Connection may be slow..."                                                                                    │
│                                                                                                                                                                                                          │
│ Step 3: Build verification                                                                                                                                                                               │
│                                                                                                                                                                                                          │
│ npm run build — fix any TS errors.                                                                                                                                                                       │
