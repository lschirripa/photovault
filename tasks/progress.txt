## Codebase Patterns
- Package manager is `npm` (not bun/yarn)
- Quality checks: `npm run type-check` (tsc --noEmit) and `npm run build` (next build)
- Branch was created from `develop` (main branch)
- Clean architecture: domain <- application <- infrastructure/presentation
- Path alias: `@/*` maps to `./src/*`
- API routes: use `createServerComponentClient()` (async), auth via `supabase.auth.getUser()`, wrap in try/catch
- Supabase join syntax: `table!inner(column)` for FK joins; cast result with `as unknown as { data: ...; error: ... }`
- RLS on media_assets enforces group membership — no manual group_members check needed
- Supabase IS NOT NULL filter: `.not("column", "is", null)`
- ALWAYS run `npm run build` to catch ESLint errors (not just `npm run type-check`)
- React hooks must be declared before any early return in component body
- r3f-globe: default import `R3fGlobe from 'r3f-globe'`, no auto-rotation (use OrbitControls), no htmlElementVisibilityModifier
- Use `next/dynamic` with `{ ssr: false }` for Three.js/R3F components
