## Codebase Patterns
- Package manager is `npm` (not bun/yarn)
- Quality checks: `npm run type-check` (tsc --noEmit) and `npm run build` (next build)
- Branch: `ralph/photo-globe` (continuing from previous work)
- Clean architecture: domain <- application <- infrastructure/presentation
- Path alias: `@/*` maps to `./src/*`
- ALWAYS run `npm run build` to catch ESLint errors (not just `npm run type-check`)
- React hooks must be declared before any early return in component body
- Use `next/dynamic` with `{ ssr: false }` for Three.js/globe components
- react-globe.gl: standalone component, NOT an R3F component, do NOT wrap in <Canvas>
- react-globe.gl manages its own scene, camera, WebGLRenderer AND CSS2DRenderer
- Access controls via ref: `globeEl.current.controls()` — returns OrbitControls instance
- r3f-globe DOES NOT render HTML markers because R3F Canvas lacks CSS2DRenderer
- Supabase join syntax: `table!inner(column)` for FK joins
- RLS on media_assets handles group membership — no manual check needed
- Use `useRef(false)` guard to prevent double-fetch in React StrictMode
