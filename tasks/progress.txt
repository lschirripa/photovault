## Codebase Patterns
- GSAP carousel uses `currentIndex` ref (float) as single source of truth for position
- `renderIndex` state (integer) triggers React re-renders for card content; `currentIndex` ref handles per-frame transforms
- `wrapIndex(index, length)` = `((index % length) + length) % length` for infinite looping
- Cards are absolutely positioned in overflow:hidden container; transforms computed from `centerX + (slotOffset - frac) * CARD_STEP`
- Scale range: 1.05 (center) → 0.75 (edge); Opacity range: 1.0 (center) → 0.7 (edge)
- GSAP context created on mount, `.revert()` on unmount for proper cleanup
- Direct `card.style.transform` writes are faster than `gsap.set()` for per-frame updates
- `snapToIndex(target, duration)` is the shared tween function — use it for drag release, click-to-center, and keyboard nav
- `activeTween` ref tracks current snap tween; kill it before starting a new drag or snap
- Velocity tracking: store last 5 `{x, t}` samples; compute velocity as `-dx / CARD_STEP / dt` (cards/second)
- `dragDistance` ref tracks pixel displacement for click vs drag threshold (5px)
- `touch-none` CSS class on container prevents browser touch scroll interference
